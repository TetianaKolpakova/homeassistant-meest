# Стан перевірки

- 23 автономні тести API, агрегації, метаданих публікації, YAML і перекладів пройдено для цього репозиторію.
- Локальним live-тестом підтверджено login, список і негайний refresh обох токенів.
- Користувач підтвердив встановлення в Home Assistant, два сенсори зі станами 1 і 0, а також атрибути номера й адреси поштомата.
- Імена, номери посилок, адреси, токени, APKM та звіти акаунта до репозиторію не включені.
- Не перевірено наживо: refresh після завершення токена, reauth, Recorder, інші статуси, інші версії HA.
- Ruff lint/format, локальна перевірка структури, перевірка приватних артефактів і збірка preview ZIP пройдені.
- GitHub owner/repository та maintainer ще не задані. Перевірка --release навмисно відхиляє такий manifest.
- GitHub Actions / hassfest / HACS мають виконатися після публікації; їхній успіх локально не заявляється.
